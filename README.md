# Telegram-мессенджер через GREEN-API

Веб-интерфейс для обмена текстовыми сообщениями в Telegram через. Пользователь подключает свой инстанс, создаёт личный чат по номеру телефона, отправляет текст и получает ответы.

## Запуск

Нужен Node.js `22.18.0`. Версия зафиксирована в `.nvmrc`.

```bash
npm ci
npm run dev
```

Проверка и сборка:

```bash
npm run lint
npm run typecheck
npm run build
npm run preview
```

## Как пользоваться

Данные берутся из кабинета GREEN-API. Инстанс должен быть в состоянии `authorized`. Чтобы ответы приходили в приложение, `webhookUrl` оставляют пустым, а входящие уведомления включают.

1. Указать `idInstance`, токен API и адрес API из кабинета, например `https://api.green-api.com`.
2. Подключиться. Приложение проверяет инстанс через `getStateInstance`.
3. Создать чат по номеру телефона. Номер проверяется через `checkAccount`.
4. Отправить текст через `sendMessage`.
5. Ответ собеседника приходит через `receiveNotification` и появляется в чате.

Можно вести несколько личных чатов. При открытии чата подгружаются последние 100 текстовых сообщений (`getChatHistory`). Отключение очищает сессию во вкладке. Инстанс в кабинете GREEN-API остаётся авторизованным.

Токен, чаты и сообщения хранятся только в памяти вкладки. После перезагрузки страницы нужно подключиться заново.
